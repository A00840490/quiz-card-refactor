Tema 8Switch

Otra estructura de control de flujo es el switch. La diferencia entre las sentencias if y else y los switch es que los switch se utilizan para comparar múltiples valores específicos.

Un switch cuenta con varios case que contienen el código que se ejecuta cuando el valor que le damos a comparar al switch es igual al que especificamos en cada case. Observa este ejemplo:

Haz clic en para recorrer el switch paso a paso.

switch.js
var codigo = "A2";

switch (codigo) {
  case "A1":
    console.log("Papas");
    break;
  case "A2":
    console.log("Galletas");
    break;
  case "A3":
    console.log("Chocolate");
    break;
  default:
    console.log("Código no válido");
}
Consola:

Analiza el código. Al inicio guardamos en la variable codigo el código que se marcó en la máquina y se lo pasamos al switch. Después se ejecutará el código en el case que coincida con ese valor. Por ejemplo, si el código es "A1", la consola muestra "Papas". Nota que tenemos un break al final de cada caso: esto le indica a JavaScript que en ese punto terminan las líneas de código que se correrán cuando se cumple el caso. Si lo quitas, JavaScript sigue de largo con el código del siguiente case.

También tenemos un caso default, y contiene el código que se ejecuta por defecto en el switch. Este debe colocarse al final, y sólo se ejecuta cuando ningún case es aceptado. Es el equivalente a utilizar una sentencia else, y es por eso por lo que si el código es diferente a A1, A2 o A3, la consola muestra "Código no válido".
