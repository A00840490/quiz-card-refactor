Tema 8Switch

Otra estructura de control de flujo es el switch. La diferencia entre las sentencias if y else y los switch es que los switch se utilizan para comparar múltiples valores específicos.

Un switch cuenta con varios case que contienen el código que se ejecuta cuando el valor que le damos a comparar al switch es igual al que especificamos en cada case. Observa este ejemplo:

Analiza el código. Al inicio de la función obtenemos el elemento input que recibe la entrada del usuario (la caja de texto) y pasamos su valor actual switch utilizando la propiedad value. Después se ejecutará el código en el case que coincida con el valor de entrada. Por ejemplo, si el valor que ingresamos es 1 entonces se asigna "El valor es 1" a la variable text. Nota que tenemos un break al final de cada caso: esto le indica a JavaScript que en ese punto terminan las líneas de código que se correrán cuando se cumple el caso.

También tenemos un caso default, y contiene el código que se ejecuta por defecto en el switch. Este debe colocarse al final, y sólo se ejecuta cuando ningún case es aceptado. Es el equivalente a utilizar una sentencia else, y es por eso por lo que si ingresamos un valor diferente a 1, 2 o 3, la página de ejemplo nos muestra que no ingresamos una entrada válida.
