Módulo 4 - Un Poco de JavaScript

Introducción

Ahora que hemos concluido las partes de HTML y CSS, nos toca aprender un lenguaje de programación: JavaScript. Este lenguaje se maneja en toda la Web y se utiliza para muchas cosas, principalmente para manipular nuestro HTML y CSS.

Las competencias que adquirirás en este módulo son las siguientes:

  • Comprender la definición de script.
  • Aprender sobre la sintaxis de JavaScript.
  • Conocer el manejo de arreglos.
  • Utilizar condicionales y ciclos.
