Tema 15Eventos

Los eventos se utilizan para ejecutar código bajo condiciones específicas para la página y sus elementos.

Existen muchos eventos en JavaScript para ejecutar código en situaciones como clics o cuando el usuario ingresa texto en un <input>.

Ejemplos

El evento que hemos utilizado a lo largo de este módulo es onclick(). En nuestros ejemplos anteriores, este evento nos sirvió para identificar cuando el usuario hace clic sobre el botón. Vinculamos nuestras funciones de JavaScript con el evento desde nuestro código HTML con el atributo "onclick". También podemos asignar funciones a estos eventos desde JavaScript. Observa los siguientes ejemplos:

Eventos en HTML

<button onclick="miFuncion()">Clic</button>

Eventos en JavaScript

Para usar eventos en JS tenemos que seleccionar al elemento:

// Opción 1: asignar una función que ya declaramos
document.getElementById("elemento1").onclick = miFuncion;
// Opción 2: asignar una nueva función al evento
document.getElementById("elemento1").onclick = function (//parámetros ) {//tu código aquí};

Otros Eventos

A continuación te enlistamos algunos de los eventos más utilizados. Puedes ver la lista completa de eventos haciendo clic aquí.

  • onmouseover: Ocurre cuando el puntero está sobre el elemento.

  • onmouseout: Ocurre cuando el puntero está sale del elemento.

  • onkeydown: Ocurre cuando se presiona una tecla.

  • onload: Cuando carga la página.

  • submit: Se sube un formulario.

  • resize: Cambia el tamaño de la ventana.

  • scroll: La ventana se desplaza.

  • dblclick: Se hace un clic doble
