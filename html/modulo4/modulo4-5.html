Tema 4Operadores

En los ejemplos anteriores utilizamos operadores para realizar asignaciones y cambiar nuestras variables. Aquí te listamos todos los operadores en JavaScript:

Operadores aritméticos
Operador Función Ejemplo de uso
+ suma var x = 2 + 5;
- resta var x = -2 - 3;
* multiplicación var x = 12 * .5;
/ división var x = 6 / 3;
% módulo (residuo de una división) var x = 8 % 5;
** potencia var x = 2 ** 8;
Operadores de asignación
Operador Función Ejemplo de uso
+= suma el valor dado al valor de la variable x += 7;
-= resta el valor dado al valor de la variable x = -2 - 3;
*= multiplica el valor dado por el valor de la variable x *= y
/= divide el valor dado por el valor de la variable x /= 2;
%= módulo del valor dado al valor de la variable x %= 3;
**= potencia el valor dado a la variable x **= -2;
++ incrementa en 1 x++;
-- decrementa en 1 x--;

Los operadores de asignación nos facilitan actualizar variables ya hechas y asignarles nuevos valores utilizando su valor anterior. Por ejemplo:

var x = 2;
x *= 8;

Modifica el valor de x mulitiplicándolo por 8. De esta forma el ejemplo de arriba es equivalente a:

var x = 2;
x = x * 8;

Simplemente es una forma más sencilla y elegante de escribir esta operación. Como te pudiste dar cuenta en la tabla, podemos realizar este tipo de operaciones tan sólo agregando un = a nuestro operador aritmético.

Concatenación

Los strings tienen un solo operador definido, y este es el operador + (suma). Este operador puede utilizarse para combinar strings secuencialmente; esto se conoce como concatenación.

var x = "Hola, "+"Mundo!"; //Después de correr esta línea, se le asigna el string "Hola, Mundo!" a la variable x
var x = "1"+"2"+"3"; //Después de correr esta línea, se le asigna el string "123" a la variable x

También podemos utilizar el operador += para agregar cadenas de caracteres al final de una variable que guarda un string.

var x = "Hola, ";
x += "Mundo!"; //Después de correr esta línea, la variable x tendrá asignado el valor de "Hola, Mundo!"
