Tema 6Condicionales

Existen algunos casos en los que no queremos que ciertas secciones del código se ejecuten. Por ejemplo: imagina que tienes algún formulario en una página. Si el usuario ingresa algún valor que no es adecuado, no queremos que el formulario sea aceptado. Podemos utilizar condiciones para verificar que los valores de entrada sean correctos.

Una condición es una declaración que da como resultado un valor booleano: True o False, que quieren decir cierto o falso respectivamente.

Las condiciones se pueden aplicar sobre el valor de una variable, el resultado de una función o la existencia de cierto elemento, entre otros. Gracias a las condiciones, podemos tomar decisiones en nuestro código y evitar errores. Estas "decisiones" las implementamos con sentencias if y sentencias else; las sentencias if y else son parte de un grupo de instrucciones de programación llamadas estructuras de control.

Operadores de Comparación

Además de operadores aritméticos y de asignación, también existen operadores para comparar valores y variables que nos sirven para crear diversas condiciones. Antes de aprender sobre if y else, es importante que conozcas estos operadores y sepas implementarlos dependiendo del caso que se te presente. Estos se utilizan principalmente dentro de los if y siempre regresan un valor booleano. Si se cumple la condición, entonces regresan True, sino False.

También puedes asignar los valores de "True" y "False" a una variable. Esto convierte a la variable a tipo booleano:

// Declaramos x como una variable booleana con valor true
var x = true;

Sentencias If y Else

Para poder tomar diferentes caminos de ejecución en nuestro código se utilizan estas palabras reservadas. Un if nos permite establecer una condición inicial: si esta se cumple (se evalúa como True), entonces se ejecuta el código dentro de ella. 

if (condición) {
// código a ejecutar si se cumple la condición
}

Una sentencia else nos permite tomar acción cuando la condición inicial no se cumple (que es cuando la condición equivale a False), pero no es obligatorio utilizarla para cada sentencia if que implementemos. Tal vez solo queremos revisar si se cumple alguna condición sin correr código cuando no se cumpla. Para agregar una sentencia else, necesitamos escribir una sentencia if antes. El siguiente ejemplo siempre ejecuta el código dentro del else; compruébalo en tu consola:

// Checamos si 2 es mayor a 3
if (2 > 3) {
console.log("2 es mayor a 3");
} else {
console.log("2 no es mayor a 3");
}

Como puedes ver, para implementar un else sólo hay que colocarlo después del cierre del if. Un else nunca tendrá su propia condición, pues únicamente se ejecutan cuando ninguna condición. Si queremos agregar múltiples condiciones para diferentes rangos de valores de una variable, podemos combinar utilizar unas sentencia else if.

Else If

Los else if son utilizados cuando la primera condición (la del if) no se cumple y aún necesitamos verificar otras condiciones. Estas condiciones se revisan consecutivamente, y solo si las condiciones anteriores a la actual no se han cumplido. Observa el ejemplo:

// Checamos si 2 es mayor a 3
if (2 > 3) {
console.log("2 es mayor a 3");
} else if (2 < 3) {
// Si la primera condición no se cumple, se revisa esta
console.log("2 es menor a 3");
} else {
// Si no se cumple ninguna de las condiciones anteriores
console.log("2 es igual a 3");
}
