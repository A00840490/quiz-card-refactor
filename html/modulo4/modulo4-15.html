Tema 14Cambiando Estilos

En la sección anterior aprendimos a acceder y modificar elementos utilizando diferentes funciones de JavaScript. Ahora aprenderemos a cambiar estilos utilizando estas mismas funciones.

Al tener acceso a un elemento, podemos cambiar cualquier aspecto de él. Para modificar o agregar alguna propiedad de estilo utilizamos la propiedad .style. Otra manera de modificar el estilo de un elemento es asignándole una clase o id distinto al cual le asignamos un estilo en nuestro código CSS.

Modificar Propiedades de CSS

Para cambiar el estilo de un elemento, seguimos el siguiente formato:

elemento.style.propiedad = "valor";

En la parte de elemento debemos tener una variable con el elemento seleccionado, y en propiedad escribimos el nombre de la propiedad que queremos modificar. Observa el siguiente ejemplo, haz clic en cada botón de lado derecho e izquierdo:

Nota que el formato para los nombres de las propiedades cambiar CSS entre CSS y JavaScript. En el ejemplo de arriba utilizamos style.fontWeight para cambiar el texto a negritas, pero en CSS utilizaríamos "font-weight". En JavaScript primera palabra del nombre de la propiedad se escribe en minúsculas y el resto de las palabras que forman el nombre de la propiedad inician con mayúsculas (este formato para los nombres se conoce como "camel case" [CSS utiliza "kebab case" para los nombres de las propiedades]).

Agregar Clases

Como mencionamos antes, también podemos tener estilos en nuestro CSS para una clase y agregar esa clase a un elemento de la página. Para esto, utilizamos la propiedad .classList que, la cual contiene un arreglo con todas las clases del elemento en formato de string. Como es un arreglo, podemos utilizar la función add() para agregarle una clase al elemento. Puedes aprender más sobre .classList haciendo clic aquí.
