Tema 1Scripts

JavaScript es muy distinto a los dos lenguajes vistos en los módulos anteriores. Podemos realizar muchas cosas con él, pero es un poco más difícil de aprender, pues hay que tener claro que este es un lenguaje de programación. Esto significa que podemos crear, cambiar y borrar diferentes tipos de datos.

Este lenguaje cuenta con muchas librerías a nuestra disposición. Las librerías son básicamente código escrito por alguien más, que cumple con alguna función específica. Una de las librerías más populares es jQuery, que nos facilita obtener y cambiar elementos de manera dinámica.

Para implementar JavaScript en nuestros proyectos, utilizamos la etiqueta <script>. Esta puede tener como src (fuente) algún archivo .js externo, o podemos simplemente escribir nuestro código JavaScript dentro de la etiqueta.

En términos simples, un script es un archivo de código ejecutable. Si colocamos una etiqueta <script> en nuestro HTML, el código será ejecutado por el navegador.

Agregar Scripts

Normalmente, los scripts se agregan al final del <body> del documento HTML, pero pueden colocarse en cualquier parte del documento. Como mencionamos anteriormente, podemos utilizar la etiqueta <script> de dos maneras, la primera ligándolo con un archivo .js externo y la segunda escribiendo directamente el código JavaScript dentro de la etiqueta:

Vinculando un Script Externo

Crea un archivo .js en tu espacio de trabajo y enlázalo a tu documento así:

<script src="nombreDeTuArchivo.js"></script>

El script no se ve en la página: el navegador descarga el archivo .js y ejecuta su código.

Creando un Nuevo Script

Haz clic en el botón EJECUTAR de la vista previa para ver lo que realiza el código:

<script>
   //Aquí va tu código JavaScript
   alert("¡Bienvenido a JavaScript!");
</script>

Esta página dice

¡Bienvenido a JavaScript!

La segunda línea del código muestra un comentario de JavaScript. Los comentarios de una sola línea inician con "//".
