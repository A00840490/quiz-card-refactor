Tema 5Arreglos

Hemos aprendido cómo utilizar variables para almacenar diferentes tipos de datos. Puede haber casos en los que necesitamos utilizar múltiples variables, lo cual implicaría tener que asignar un nombre a cada una. Esto claramente no es muy conveniente cuando necesitamos 100 o 200 variables, por lo que existe una forma de guardar muchos datos con un mismo nombre. A este tipo de variables se denomina arreglo ("array" en inglés), los cuales son muy útiles y están presentes en todos los lenguajes de programación. En otros lenguajes, los arreglos como listas de un tipo de dato en específico, pero en JavaScript podemos asignar cualquier tipo de dato a un elemento de un arreglo.

Los arreglos cuentan con varias funciones que nos ayudan a modificarlos u obtener información sobre ellos y sus elementos, como saber su longitud, agregar o borrar elementos, y ordenar los elementos, entre muchas otras.

Tienes las calificaciones de 5 alumnos. ¿Cómo las guardas?

Con lo que llevas del curso, harías una variable para cada una.

200 alumnos son 200 variables, cada una con su nombre.

Imagina sacar el promedio así. Tiene que haber una forma de guardarlas todas juntas.

Un arreglo guarda muchos valores con un solo nombre

Para declararlo también utilizamos la palabra reservada var, con una pequeña variación: encerramos entre corchetes [ ] una lista separada por comas con todos los valores que queramos guardar.

// Un arreglo con las 5 calificaciones
var calificaciones = [90, 75, 88, 100, 62];
// También puede empezar vacío
var lista = [];

¿Cómo sacas la calificación del tercer alumno?

Cada valor tiene un índice, y los índices empiezan en 0

El índice es la posición de un valor en el arreglo: al primero le toca el 0, al segundo el 1 y así sucesivamente. Escribimos el nombre del arreglo y el índice entre corchetes para leer un valor, y con lo mismo lo cambiamos:

// Leemos la calificación del tercer alumno
console.log(calificaciones[2]);
// Y la cambiamos por otra
calificaciones[2] = 95;

Métodos de Arreglos

Los arreglos forman parte de un tipo de datos conocido como objeto. A las funciones de un objeto se les conocen como métodos. Los objetos también pueden tener propiedades, que son valores asignados a un objeto. Tienen el mismo comportamiento que una variable, pero están asociadas con el objeto. Para utilizar los métodos y propiedades de un objeto, solo escribimos el nombre de nuestro arreglo, seguido de un punto y el nombre del método o propiedad. Aquí hay algunos ejemplos con el arreglo miArreglo:

.length: Regresa la longitud del
                                                    arreglo. (En realidad no es una función, sino una variable del objeto
                                                    arreglo, por lo que no lleva paréntesis).

                                                


var miArreglo = ["Hola", "Mundo", 7];
var longitud = miArreglo.length; // 3
// Imprime el último elemento del arreglo (índice 2)
console.log(miArreglo[miArreglo.length - 1]);

                                                


                                                
.pop(): Elimina el último elemento del
                                                    arreglo.

                                                


var miArreglo = ["Hola", "Mundo", 7];
miArreglo.pop(); // Se elimina el 7

                                                

                                                
.push(elemento): Agrega un
                                                    elemento al final

                                                


var miArreglo = ["Hola", "Mundo", 7];
// El arreglo ahora es ["Hola", "Mundo", 7, "nuevo"]
miArreglo.push("nuevo");

                                                


                                                
.shift: Elimina y regresa el primer
                                                    elemento.

                                                


var miArreglo = ["Hola", "Mundo", 7];
// primero = "Hola"; el arreglo queda ["Mundo", 7]
var primero = miArreglo.shift();

                                                

                                                
.unshift(elemento): Agrega un
                                                    elemento al inicio del arreglo.

                                                


var miArreglo = ["Hola", "Mundo", 7];
// El arreglo ahora es [5, "Hola", "Mundo", 7]
miArreglo.unshift(5);

                                                


                                                
.splice(indice, n. de elementos,
                                                                valores): Agrega y borra elementos de acuerdo
                                                    a su posición. Regresa un arreglo con los elementos borrados. El primer
                                                    parámetro es el índice en donde se agregarán elementos, el segundo es el
                                                    número de elementos a eliminar y los siguientes son los valores que se
                                                    agregan.

                                                


var miArreglo = ["Hola", "Mundo", 7];
// miArreglo queda ["Hola", 8, "world"]
var borrados = miArreglo.splice(1, 2, 8, "world");

                                                

                                                
Si no ponemos parámetros con valores para agregar, podemos usarlo para
                                                    eliminar elementos en posiciones específicas:

                                                


var miArreglo = ["Hola", "Mundo", 7];
// miArreglo queda ["Hola", 7]
miArreglo.splice(1, 1);

                                                

                                                
.slice(índice inicial, índice
                                                                límite): Similar a .splice pero no elimina ni agrega elementos. Sólo
                                                    accede a porciones específicas de un arreglo y las regresa. Puede tener hasta
                                                    dos parámetros, ambos índices del arreglo que serán el intervalo de
                                                    elementos a copiar. El segundo parámetro es el límite, si sólo hay uno,
                                                    copia todo a partir del primer índice.

                                                


var miArreglo = ["Hola", "Mundo", 7];
var miArreglo2 = miArreglo.slice(1, 2); // ["Mundo"]
var miArreglo3 = miArreglo.slice(0, 2); // ["Hola", "Mundo"]
var miArreglo4 = miArreglo.slice(1);    // ["Mundo", 7]
