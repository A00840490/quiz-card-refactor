Tema 18Enlaces

Estilizar enlaces es prácticamente igual que estilizar texto. Por defecto, cuando colocamos un enlace en HTML, nuestro texto cambia a color azul y se subraya. Podemos modificar su estilo utilizando las propiedades que vimos anteriormente, como text-decoration y color.

También podemos modificar el estilo del enlace cuando el usuario hace clic sobre él o pasa el puntero sobre el texto. Esto se logra a través de pseudoclases de CSS, que se utilizan para modificar un elemento solo bajo ciertas condiciones. En los enlaces se utiliza la pesudoclase hover para modificar el texto cuando el usuario pasa el puntero del mouse sobre él. Este ejemplo muestra cómo se utilizan:

a{
    font-size: 30px;
    text-decoration: none;
}

a:hover{
    color: red;
}

Este enlace se hace rojo cuando pasas sobre él.
