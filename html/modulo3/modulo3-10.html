Tema 9Más Propiedades

CSS cuenta con numerosas propiedades para estilizar nuestro contenido. Aquí te listamos algunas que pueden implementarse con colores. Recuerda que puedes utilizar cualquier formato de color.

1. color

Especifica el color del texto.

2. background-color

Especifica el color del fondo del elemento. Alternativamente puedes utilizar background, ya que combina múltiples propiedades del fondo. También podemos utilizar un gradiente para el color de fondo. Puedes ver más ejemplos dando clic aquí.

3. border-color

Especifica el color del borde del elemento. Se necesita especificar un estilo de borde utilizando la propiedad border-style. Alternativamente puedes utilizar la propiedad border, ya que puede combinar la asignación del estilo con el color.

4. box-shadow

Le añade una sombra al contenedor con el color especificado.

5. text-shadow

Agrega una sombra del color especificado al texto.

6. text-decoration-color

Cambia el color de la decoración aplicada al texto.
