Tema 9Más Propiedades de Color

CSS cuenta con numerosas propiedades para estilizar nuestro contenido. Aquí te listamos algunas que pueden implementarse con colores. Recuerda que puedes utilizar cualquier formato de color.

Mueve el control deslizante para recorrer cada capa del botón.

text-decoration-color

Cambia el color de la decoración aplicada al texto, como el subrayado.

color

Especifica el color del texto.

text-shadow

Agrega una sombra del color especificado al texto.

border-color

Especifica el color del borde del elemento. Se necesita especificar un estilo de borde utilizando la propiedad border-style. Alternativamente puedes utilizar la propiedad border, ya que puede combinar la asignación del estilo con el color.

background-color

Especifica el color del fondo del elemento. Alternativamente puedes utilizar background, ya que combina múltiples propiedades del fondo. También podemos utilizar un gradiente para el color de fondo; puedes ver más ejemplos aquí.

box-shadow

Le añade una sombra al contenedor con el color especificado. Es lo primero que se pinta, así que queda detrás de todo.

.boton

Juntas, las seis capas forman el botón. Así se ve el código completo, en el orden en que el navegador las pinta, de atrás hacia adelante.
