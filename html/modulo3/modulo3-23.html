Tema 22Grid

La propiedad flex tiene algunas limitantes, la más relevante siendo que solo trabaja en una dirección, de acuerdo con la propiedad flex-direction. Grid es una propiedad más avanzada, pues permite estilizar nuestro espacio como una cuadrícula, la cual tiene dos dimensiones, usando filas y columnas. Para implementarlo, utilizamos display: grid; y después tenemos que especificar los tamaños de nuestras filas y columnas con las propiedades: grid-template-rows y grid-template-columns; puedes especificar uno o ambos. Esto se puede hacer de diferentes maneras; observa los siguientes ejemplos:

  • grid-template-rows: 100px 1fr;
    Dos renglones, uno de 100px y otro de 1fr. (fr es una unidad exclusiva de grid).

  • grid-template-rows: minmax(100px, 1fr);
    La función minmax nos da un rango mínimo y máximo de valores que puede tener el renglón o columna.

  • grid-template-rows: repeat(3, 200px);
    La función repeat repite los valores. El primer número indica la cantidad de veces a repetir y el segundo el tamaño, por lo que en este caso tendremos tres renglones de 200px.

Además de estas, se pueden aplicar las propiedades align-content y justify-content como en flexbox. Otras propiedades que se pueden aplicar a un contenedor grid son:

  • grid-row-gap Especifica el espacio entre cada renglón.

  • grid-column-gap Especifica el espacio entre cada columna.

  • grid-gap Especifica el espacio entre cada renglón y columna.

    • Estas propiedades se utilizan en los elementos del contenedor para especificar el espacio del grid que tomarán:

  • grid-column-start Indica la columna en la que comenzará el elemento.

  • grid-column-end Indica la columna en la que terminará el elemento.

  • grid-row-start Indica el renglón en el que comenzará el elemento.

  • grid-row-end Indica el renglón en el que terminará el elemento.

  • grid-area Se utiliza para los 4 anteriores. También puede utilizarse con grid-template-areas para especificar áreas del grid a utilizar. El ejemplo de abajo utiliza esto.
