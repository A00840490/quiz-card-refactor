Tema 6 Elementos Dentro de una División

En CSS podemos ser aún más específicos y seleccionar elementos dentro de otros elementos. Esto se hace escribiendo selectores consecutivos separados por espacios, donde se seleccionan elementos internos de izquierda a derecha.

See the Pen bGwqJRR by Luis Yerik Arambula (@luis-yerik-arambula) on CodePen.

CodePen. Software utilizado para el desarrollo de ejercicio dinámico de programación. In CodePen. https://codepen.io

En este ejemplo, el único texto azul es el del párrafo que está dentro de un elemento con la clase azul. El encabezado no es azul, pues, aunque está dentro de la división, no está dentro de un párrafo. El último párrafo tampoco es azul porque no está dentro de un elemento con la clase azul asignada.
