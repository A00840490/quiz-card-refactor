Tema 4Atajos de Clases e IDs

VS Code nos facilita agregar clases e IDs a elementos nuevos. Para esto podemos escribir el nombre del tipo de elemento seguido de un "." o un "#" y el nombre de la clase o ID.


Podemos agregar múltiples clases al elemento iniciando cada nombre por un ".".

A diferencias de las clases, no podemos agregar más de un ID a un elemento.
