Módulo 3 - Decorando con CSS

Introducción

Con el ejercicio del módulo anterior construimos una página web bastante sencilla utilizando solo HTML, pero esa página no se ve del todo bien, o al menos no se ve como una página web moderna. Por ejemplo, este curso que cuenta con una fuente de texto diferente, con colores, menús y muchas otras características que no se pueden agregar a una página utilizando HTML exclusivamente. Para agregar estas modificaciones de estilo, utilizamos CSS.

CSS significa "Hojas de Estilo en Cascada" (Cascading Style Sheets), y es un tipo de documento que nos permite añadir estilos a nuestros elementos HTML en un formato sencillo de entender.

Las competencias que adquirirás en este módulo son las siguientes:

  • Conocer lo básico sobre el lenguaje de estilo CSS.
  • Identificar tamaños y responsividad adecuados.
  • Integrar diferentes fuentes de texto, colores y rellenos.
  • Modificar el posicionamiento de elementos.
