Tema 21Flexbox

La llegada de CSS3 trajo consigo dos nuevas herramientas para posicionar nuestros elementos: estas son flexbox y grid. Las funciones de ambas se consideran como CSS avanzado, por lo que no las veremos muy a fondo, pero es importante que las conozcas. Ambas se implementan utilizando la propiedad display.

Display

Esta propiedad cambia la forma en la que se muestra el contenido. Tiene dos valores por defecto los cuales son: inline para objetos de línea (enlaces, spans, labels) y block para objetos de bloque (divisiones, párrafos, listas). Existen otros valores, como inline-block que combina los dos anteriores. Observa su uso en este ejemplo.

Flexbox

Flexbox quiere decir "caja flexible", y es una propiedad muy poderosa que se utiliza para que nuestros elementos se acomoden de acuerdo al tamaño de página con una implementación sencilla. Para utilizarla, solo tenemos que agregar display: flex; a nuestro elemento padre, con esto, todos los elementos dentro del elemento se convertirán en cajas flexibles, y se les podrá aplicar una serie de propiedades. Existen propiedades flex para el contenedor y para los hijos; las propiedades del contenedor afectan todos los hijos. Las propiedades del contenedor flex son:

  • flex-direction
    Cambia la dirección en la que se acomodan los elementos. La predeterminada es row, la cual acomoda a los elementos de manera horizontal de izquierda a derecha.

  • flex-wrap
    Si el contenido no cabe en la dirección que se tiene, entonces se "rodea" con el valor wrap.

  • align-items
    Modifica cómo se alinean los elementos respecto a los demás.

  • justify-content
    Modifica cómo se justifica el contenido.

  • align-content
    Modifica cómo se alinean los elementos respecto al contenedor.

Propiedades de los elementos flex:

  • align-self
    Alinea sólo al elemento dentro del contenedor. Esta propiedad anulará la propiedad align-items sólo en el elemento.

  • flex-grow
    Especifica el tamaño con el que crecerá un elemento con respecto a los demás. Su valor predeterminado es 0.

  • flex-shrink
    Especifica el tamaño con el que decrecerá un elemento con respecto a los demás. Su valor predeterminado es 1.

  • flex
    Combina las tres propiedades anteriores.

  • order
    Cambia el orden de los elementos; el valor debe de ser un número, el más bajo va primero.
