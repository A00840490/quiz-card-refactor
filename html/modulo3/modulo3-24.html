Ejercicio 3

Este ejercicio está diseñado para probar tus conocimientos teóricos y prácticos de CSS. Te presentaremos varios casos con código CSS incompleto, de acuerdo a lo que se pida, tendrás que completarlo para cumplir con la modificación requerida. Responderás una pregunta a la vez y verás cómo cada respuesta cambia la vista previa. Al terminar verás cuántos aciertos tuviste.

Recuerda que puedes regresar al módulo para revisar cualquier duda que tengas; esto no será evaluado por ningún agente externo, pero te servirá como retroalimentación de lo que has aprendido.
