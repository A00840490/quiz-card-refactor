Tema 10Formularios

Los formularios son elementos que nos permiten obtener información de los usuarios de nuestra página web. Esta información normalmente se envía al servidor del sitio web para ser procesada. Para definir un formulario utilizamos la etiqueta <form> que contendrá todos los diferentes elementos del formulario. Los elementos más utilizados dentro de los formularios son <input>, <label> y <select>.

Por lo general, se especifica el action en la etiqueta <form>, el cual especifica la acción que realiza la página web después de presionar el botón de "enviar". Si dejas vacío este atributo, el formulario te redirigirá a la misma página. La etiqueta form también puede tener el atributo method, que especifica el método HTTP para enviar las entradas del usuario.

El siguiente ejemplo utiliza todos los elementos mencionados anteriormente:

<!DOCTYPE html>
<html lang="en">
<head>
<title>Formularios</title>
</head>
<body>
   <form action="/manejarFormulario" method="POST">
      <label for="usuario">Usuario:</label>
      <input type="text" id="usuario" name="usuario" placeholder="Tu usuario"><br>
      <label for="pwd">Contraseña:</label>
      <input type="password" name="pwd" id="pwd"><br>
      <label>Sexo:<//label>
      <label for="hombre">Hombre</label>
      <input type="radio" name="sexo" id="hombre" value="hombre">
      <label for="mujer">Mujer</label>
      <input type="radio" name="sexo" id="mujer" value="mujer"><br>
      <label for="pais">País:</label>
      <select name="pais" id="pais">
      <option>Estados Unidos</option>
      <option>Canadá</option>
      <option selected>México</option>
      <option>Otro</option>
      </select> <br>
      <label for="terminos">Aceptas los términos</label>
      <input type="checkbox" name="terminos" id="terminos" value="aceptar"><br>
      <input type="submit" value="Enviar!">
   </form>
</body>
</html>

Vayamos por pasos: primero, observamos que casi todo el formulario consiste de etiquetas <label> e <input>. Las etiquetas <label> se utilizan para describir lo que queremos que el usuario responda para un <input>. En cambio, las etiquetas input nos ayudan a crear los espacios para las entradas del usuario en nuestro formulario.

En la mayoría de los casos, la mejor práctica es tener un <label> por cada <input>.

Los labels se asocian con los inputs gracias al atributo for, el cual debe ser igual al atributo id asignado al <input>. En el ejemplo tenemos el <label> con el contenido "Usuario:" con el atributo for="usuario", que lo asocia con el <input> posterior que tiene id="usuario" asignado.

Las asociaciones de label con entrada ocurren para todos los elementos del formulario. Los labels también nos ayudan con las entradas con type="radio", ya que podemos hacer clic junto al texto para hacer las selecciones, pruébalo en el ejemplo de arriba.

Antes de continuar explicando el resto de los atributos, hay que entender e identificar los diferentes tipos de <input> que podemos utilizar en un formulario. El atributo type define el tipo de entrada que se recibirá en un elemento input:

  • type="text" Muestra una caja de texto.

  • type="password" Permite que el usuario escriba una contraseña (sin mostrar lo que escribió).

  • type="radio" Se utiliza para preguntas de opción múltiple.

  • type="checkbox" Es un recuadro que el usuario puede o no marcar.

  • type="date" Pide una fecha al usuario.

  • type="email" Le pide al usuario un correo electrónico en el formato adecuado: nombre_de_usuario@dominio.

  • type="file" Permite que el usuario seleccione un archivo de su computadora.

  • type="submit" Se utiliza para el botón que envía la información del formulario al presionarlo.

Existen más tipos de elementos que podemos utilizar. Puedes consultar la lista completa haciendo clic aquí.

Continuemos con el ejemplo: en el primer <input> utilizamos el atributo placeholder. Este lo podemos usar cuando queramos tener un texto en nuestra área de entrada, usualmente con el objetivo de mostrar un ejemplo de lo que el usuario debe ingresar en la caja.

El atributo más importante para los inputs es name, ya que su función es indicar el nombre de la información al servidor. Gracias a que estos nombres se emparejan con el valor que ingresa el usuario, podemos manejar la información en el back-end o referenciar el elemento con JavaScript con facilidad. Cuando tenemos un <input> con type="radio", name nos ayuda a separar las opciones para cada pregunta. Como podrás notar, los inputs de hombre y mujer tienen el mismo atributo name asignado: name="sexo". Es por esto que solo podemos seleccionar una de las 2 opciones que le damos al usuario.

Otro atributo común es value. Este atributo tiene diferentes usos dependiendo del type que estemos utilizando.

  • Para type="text" y type="password" define un valor por defecto dentro de la caja.
  • Para type="radio" define el valor que se envía cuando la opción está seleccionada. En los inputs de sexo se envía "hombre" o "mujer" dependiendo de la selección del usuario.
  • Para type="button" y type="submit" define el texto que se muestra en el botón para enviar el formulario.

Por último, tenemos la etiqueta <select>, que se utiliza para seleccionar opciones de un menú desplegable. Las opciones se definen usando la etiqueta <option>. Esta etiqueta también utiliza los atributos id y name con el mismo propósito que los elementos input. También podemos añadir un atributo global selected en alguna de las opciones del menú desplegable para seleccionarlo por defecto. Si queremos separar las opciones por grupo podemos añadir la etiqueta <optgroup> que encerrará a las opciones del grupo.

Ahora que ya sabes cómo hacer formularios, intenta agregar uno a tu código anterior. Utiliza todos los elementos y tipos que quieras.
