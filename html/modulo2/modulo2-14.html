Llegamos casi al final de este módulo de HTML. Prácticamente conoces todos los elementos necesarios para estructurar una página web. En esta sección conocerás otros elementos HTML que pueden ser útiles para algunos sitios: iframes, tablas y spans. También aprenderás sobre las entidades, que sirven para agregar caracteres especiales a tu código.

Iframes

Los iframes pueden ser un tanto confusos, pero podemos verlos como un marco que puede contener otra página web, tanto interna como externa a tu sitio. Un ejemplo de uso es mostrar vídeos de YouTube a tus usuarios. Para implementar estos elementos se utiliza la etiqueta <iframe>. Para todo iframe se necesita definir el atributo src, que le indica al navegador el URL de la página que debe mostrar dentro del marco. También podemos agregar los atributos width y height para modificar el tamaño de nuestro contenido como con las imágenes en HTML. Observa cómo funciona: el hueco de tu página es el iframe y detrás está la página que pide src.
