Iframes

Los iframes pueden ser un tanto confusos, pero podemos verlos como un marco que puede contener otra página web, tanto interna como externa a tu sitio. Un ejemplo de uso es mostrar vídeos de YouTube a tus usuarios. Para implementar estos elementos se utiliza la etiqueta <iframe>. Para todo iframe se necesita definir el atributo src, que le indica al navegador el URL de la página que debe mostrar dentro del marco. Framework

Framework quiere decir entorno de trabajo, el cual consiste en una serie de herramientas y prácticas que nos ayudan a resolver cierto problema. En el contexto del desarrollo web, un framework nos da soporte con módulos y librerías para facilitar nuestro código, o utilizar funciones que serían más complicadas de implementar sin este. Por ejemplo, existen frameworks para incorporar Python en desarrollo web como Django o Flask.

Lenguaje

Un lenguaje en el contexto de programación web es una serie de reglas e instrucciones que permiten realizar cierto tipo de acciones o añadir cierto formato a algún elemento. En este curso aprenderás las nociones de los 3 lenguajes pilares de la programación web y todas sus instrucciones básicas para crear páginas web.
