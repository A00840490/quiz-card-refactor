Tema 2 Encabezados

Como mencionamos anteriormente, el elemento de encabezado <h1></h1> usualmente encierra el título de nuestra página o sección, y cuenta con seis niveles, siendo 1 el de mayor tamaño y el 6 para el menor.

Modifica tu documento HTML en VS Code para incluir los 6 tipos de encabezados. Recuerda que las etiquetas de encabezados son cerradas. Tu código debería verse algo así:

<!DOCTYPE html>
<html lang="en">
<head>
   <meta charset="UTF-8">
   <meta name="viewport" content="width=device-width, initial-scale=1.0">
   <title>Document</title>
</head>
<body>
   <h1>Encabezado 1</h1>
   <h2>Encabezado 2</h2>
   <h3>Encabezado 3</h3>
   <h4>Encabezado 4</h4>
   <h5>Encabezado 5</h5>
   <h6>Encabezado 6</h6>
</body>
</html>

Para visualizar tus cambios primero tienes que guardar tu código presionando Ctrl + S o yendo al menú de Archivo/File en tu editor y presionando el botón de Guardar/Save. Recuerda activar la función de Go Live en VS Code si no la tienes activada para tu proyecto.
