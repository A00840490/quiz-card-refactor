Enlaces a Otras Páginas del Mismo Sitio

Este tipo de enlaces se usa todo el tiempo para navegar por el diferente contenido de un sitio web, normalmente en barras de navegación. En lugar de poner una URL en el atributo href, ponemos la ruta al archivo de la parte de nuestro sitio a la que queremos navegar.

El siguiente ejemplo contiene un enlace al inicio del curso:

<a href="Bienvenida.html"><p>De vuelta al inicio del curso.</p></a>

De vuelta al inicio del curso.

Enlaces a Otras Partes de la Misma Página

Estos enlaces los podemos utilizar para facilitarle la navegación al usuario. Al tener mucho contenido, es más fácil presionar un enlace para regresar al inicio o ir hacia el final de una sección en lugar de desplazarnos con el mouse. Para esto en el atributo href, ponemos un # y el id de algún elemento en nuestro documento HTML. El id es un atributo global (que se puede utilizar en cualquier elemento HTML). Este funciona como identificador único del elemento.

El siguiente ejemplo contiene un enlace al inicio de esta misma página:

<a href="#inicio"><p>Inicio de la sección.</p></a>
