Tema 1Estructura Básica

Las instrucciones de HTML se escriben en formato de etiquetas ("tags" en inglés) y se identifican fácilmente porque están encerradas por los caracteres "<" (menor que) y ">" (mayor que). Las etiquetas se clasifican en dos tipos: de cierre y apertura.

Las etiquetas de apertura marcan el inicio de un elemento. Su formato es: <etiqueta>, donde "etiqueta" es el nombre del tipo de elemento HTML.

Las etiquetas de cierre son aquellas que marcan el final de un elemento, y se distinguen por tener una diagonal después del signo de menor que: </etiqueta>. En el documento de ejemplo, head encierra las etiquetas de metadatos y el título del documento. Siempre existe una correspondencia 1 a 1 entre una etiqueta de cierre y una de apertura. En el documento de ejemplo, el elemento head encierra a los elementos de metadatos (meta) y el elemento de título (title).

Pero no todos los elementos HTML requieren de una etiqueta de cierre. En el documento de ejemplo, las etiquetas de metadatos son elementos HTML que no requieren de una etiqueta de cierre.

Atributos

Los atributos definen las características de los elementos HTML. Los atributos siempre se escriben junto a la etiqueta de apertura de un elemento separados por espacios o saltos de línea. El formato es el siguiente: nombre-de-atributo="valor del atributo", donde nombre de atributo se reemplaza por el nombre del atributo que se quiere modificar, y valor del atributo se reemplaza por el valor que se le quiere asignar al atributo. En el código de ejemplo, lang="en" modifica el atributo de lenguaje del elemento raíz del documento para que los buscadores (como Google o Bing) detecten inglés para el idioma de la página. Elementos principales

  • <html></html> Todo el contenido del documento HTML debe estar dentro de esta etiqueta. Se suele incluir el parámetro lang que especifica el lenguaje de la página para los buscadores (como Google o Bing).
  • <head></head> Contiene el encabezado del documento. Dentro de este se colocan etiquetas que proporcionan datos sobre la página, por ejemplo, el título de la página. No se coloca ningún tipo de contenido en esta sección.
  • <title></title> Contiene el título de la página, este es el nombre que se despliega en la pestaña de tu navegador.
  • <link> Especifica una conexión con un archivo externo. Un uso común de este elemento es para agregar archivos CSS para estilizar nuestra página.
  • <meta> Se utiliza para especificar metadatos que le pueden ser útiles al navegador como caracteres, descripción, palabras clave, etc.
  • <body></body> Encierra todo el contenido de la página web: texto, imágenes, formularios, enlaces, etc.
  • <p></p>Encierra un párrafo.
  • <h1></h1> Se utiliza para agregar títulos principales. Existen variaciones de este elemento para disminuir el tamaño del título, desde h1 a h6 (h1, h2, h3 ..., h6).
  • <a></a> Define un hipervínculo, es decir, un enlace a otra página o una ruta dentro de la misma página. Se utiliza con el atributo href para indicar hacia donde navegar.
  • <script> ó <script></script> Define o importa un script, que es una serie de instrucciones de código; escrito en JavaScript.
