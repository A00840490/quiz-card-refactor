Módulo 2 - Formato y Estructura de HTML

Introducción

En el tutorial del módulo anterior creamos nuestro primer documento HTML. Los documentos HTML forman el esqueleto de todas las páginas web. El lenguaje tiene todas las herramientas para definir el formato de las páginas y permite incluir imágenes, formularios, botones e incluso enlaces (también conocidas como "ligas") a otros documentos.

Nuestros navegadores interpretan los documentos HTML para que podamos visualizarlos. Puedes hacer clic derecho y dar clic en "Inspeccionar" o "Ver código fuente de la página" para visualizar en tu navegador el código HTML de cualquier página en la que te encuentres. ¡Inténtalo!

Las competencias que adquirirás en este módulo son las siguientes:

  • Reglas generales de HTML.
  • Conocimiento sobre elementos de HTML como encabezados, listas, párrafos, formularios, etc.
  • Estructuramiento básico de páginas web.
