Spans

Los spans son elementos que se utilizan como contenedores de cierta parte de texto u otro elemento para que esta sea manipulado con facilidad. Su etiqueta es <span> y usualmente contienen algún id o class para que ese segmento específico sea modificable con CSS. En este ejemplo usamos el atributo que vimos anteriormente style para modificar una parte de un texto.

<p> El agua es color <span style="color: blue;"> azul </span> </p>

El agua es color azul

Entidades

Estás escribiendo el contenido de tu página web cuando te das cuenta de que necesitas colocar un <, ¿cómo lo haces si este carácter se usa para definir etiquetas en el código? Este, junto con otros caracteres, está reservado por HTML, así que recurrimos a lo que llamamos entidades para utilizarlos, dentro de nuestras páginas.

Las entidades son simplemente estos caracteres escritos de una manera diferente para que el navegador pueda identificarlos como parte del contenido y no como parte del código HTML. Para utlizarlos colocamos el símbolo & seguido de su código; cada entidad tiene un código único. Aquí te listamos algunos caracteres especiales para que puedas utilizarlos en tu contenido:

Cáracter Descripción Nombre de la Entidad Número de la Entidad
Espacio sin ruptura &nbsp; &#160;
< menor que &lt; &#60;
> mayor que &gt; &#62;
& ampersand &amp; &#38;
" comillas dobles &quot; &#34;
' comilla &apos; &#39;
© copyright &copy; &#169;
® marca registrada &reg; &#174;

Observa este ejemplo:


<p> 5 es &lt; que 6 </p>

5 es < que 6
