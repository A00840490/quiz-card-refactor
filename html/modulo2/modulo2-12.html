Tema 11Enlaces

Los enlaces o hipervínculos son elementos muy comunes en todas las páginas web. Nos permiten navegar a través de todo el contenido de nuestro sitio y navegar hacia páginas ajenas a las nuestras. Para implementar un enlace, se utiliza la etiqueta <a> junto con su atributo href, que contiene la dirección a la que se quiere navegar cuando das clic en el contenido encerrado por el elemento. Esta dirección puede ser una URL de otro sitio web, la ruta de un documento de nuestro propio sitio web o también otra parte de la página web actual.

Los enlaces no necesariamente se aplican únicamente al texto de una página. De hecho, podemos utilizarlos para cualquier elemento HTML.

Por defecto, los enlaces pueden aparecer de diferentes formas de acuerdo a nuestras interacciones con ellos:

  • Un enlace sin visitar se encuentra subrayado y azul.

  • Un enlace visitado se encuentra subrayado y morado.

  • Un enlace activo se encuentra subrayado y rojo.

Enlaces a Páginas Externas

El atributo target nos permite manejar cómo se abre nuestro enlace: si le asignamos el valor target="_blank" el enlace se abrirá en una pestaña nueva; con target="_self" (o sin target) se abre en la misma pestaña.

Pruébalo en el siguiente tablero: la hoja de la izquierda es la página del código y el estambre une su enlace con el sitio al que lleva. El plumón marca la parte en la que se puede hacer clic y la tachuela del enlace toma su color: azul, rojo o morado.

Haz clic en el enlace para seguirlo, o en los valores del código para cambiarlo.
