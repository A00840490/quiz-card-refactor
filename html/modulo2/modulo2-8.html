Tema 7Listas Descriptivas

Este tipo de lista es el menos utilizado, cada elemento de la lista es un término y su descripción. Su etiqueta es <dl> por su nombre en inglés, description list. Utilizan etiquetas diferentes a las listas normales, <dt> para definir términos y <dd> para agregar descripciones a ellos. Una aplicación común de estos elementos es para crear un glosario en una página web.

<dl>
<dt> Café </dt>
   <dd> Bebida caliente oscura </dd>
<dt> Leche </dt>
   <dd> Bebida fría de color blanco </dd>
</dl>

El código anterior se ve de la siguiente manera:

Café
Bebida caliente oscura
Leche
Bebida fría de color blanco

En este ejemplo podemos ver como los dos términos son café y leche, y sus descripciones se indentan junto a los términos.
