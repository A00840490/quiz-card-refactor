Tema 4 Frameworks

Ya que hayas contratado tu dominio y un buen plan de alojamiento, tienes todo listo para publicar tu sitio web. El servicio de hosting también puede variar dependiendo si elegiste utilizar algún framework para tu proyecto. En el módulo 1 vimos el concepto de framework: que son un conjunto de herramientas y librerías que nos permiten añadir nuevas funcionalidades a nuestras páginas o facilitar procesos en nuestro desarrollo.

Como principiante, es probable no hayas utilizado un framework o librería en tu proyecto, pero es importante que conozcas algunas de estas herramientas. Ahora que tienes las bases de HTML, CSS y JavaScript, puedes aventurarte a aprender sobre frameworks y librerías para crear páginas con mayor facilidad.

Algunas de estas herramientas que podrán ayudarte en la creación de páginas web son:

Bootstrap

Bootstrap es uno de los frameworks más utilizados de Internet. Se puede utilizar para páginas pequeñas y hasta para páginas empresariales más grandes. Nos brinda cientos de funcionalidades que nos ahorran mucho tiempo de codificar, consiste en muchos archivos CSS, JavaScript y Sass (un framework de CSS) que nos permiten utilizar cientos clases para estilizar nuestros elementos. Puedes leer más acerca de él y descargarlo aquí.

jQuery

jQuery es probablemente la librería de JavaScript más utilizada. Esta nos facilita la selección de elementos y la modificación dinámica de elementos.

En jQuery se utiliza el caracter $ para seleccionar elementos. Por ejemplo, para obtener un elemento con un ID, escribimos el siguiente código:
var elemento = $("nombredelID");.

Puedes descargar jQuery haciendo clic aquí.

React

React es una poderosa librería de JavaScript que nos permite crear interfaces de usuario de manera más fácil y rápida. También nos permite crear y reutilizar elementos personalizados. React utiliza una sintaxis denominada JSX, que combina JavaScript y HTML para crear componentes. Una ventaja de esta librería es que cuenta con tutoriales y documentación en español en su sitio oficial. Puedes ver estos recursos haciendo clic aquí.
