Módulo 5 - Publicar a la Web

Introducción

¡Hemos concluido con la porción de programación del curso! Ahora cuentas con las bases para crear tus páginas web usando HTML, CSS y JavaScript.

Con tu sitio web terminado, ha llegado el momento de dar el gran paso y publicarlo en Internet. En este módulo aprenderás sobre este último paso, que, aunque puede no ser tan extenso como programar y diseñar las páginas, es igual de importante, pues es la puerta de acceso a tus próximos usuarios o clientes.

En este módulo también aprenderemos sobre otras herramientas que nos pueden facilitar la creación de sitio web.

Las competencias que adquirirás en este módulo son las siguientes:

  • Comprender el funcionamiento de los sitios web.
  • Aprender el concepto de hosting.
  • Conocer sobre el manejo de dominios.
  • Aprender sobre algunos frameworks.
