Tema 2Hosting

Establecimos en la sección pasada que necesitaremos algún servidor para tener nuestras páginas web. A esto se llama alojamiento, o hosting en inglés.

Hay muchas opciones para alojar nuestro sitio web, la gran mayoría son de paga, pero no son muy caras. De hecho, hay muchas opciones buenas y flexibles, que varían en recursos de acuerdo con el plan que elijas.

Normalmente se pagan mensualmente como cualquier suscripción. Un plan sencillo va desde 50 a 150 MXN al mes.

Escogiendo Alojamiento

Basta con sólo googlear alojamiento web para que nos sean presentadas miles de opciones para publicar nuestra página web, ¿cómo podemos decidir?

Debemos buscar una buena opción como si buscáramos un hotel para quedarnos. Queremos que nuestra página sea accesible, que no cueste demasiado dinero y que tenga suficientes recursos. Esto último es muy importante, pues definirá parte de la calidad de tu página y la experiencia del usuario en ella. Normalmente se te ofrecerán los siguientes recursos:

  • Almacenamiento: Necesitarás espacio de almacenamiento para guardar todos los archivos de tu proyecto; de 10 a 20 GB serán suficientes para páginas pequeñas.

  • Ancho de banda: El ancho de banda es lo que determina qué tan rápido se intercambian datos entre el servidor y tu página. Entre más visitantes tengas, más ancho de banda necesitarás.

  • Seguridad: Lo más recomendable es tener acceso al protocolo SSH, el cual encripta la información de nuestra página y protege los datos de nuestros usuarios. No todos los planes de alojamiento ofrecen esto.

  • Servicio al cliente: Si ocurre algún error desconocido en el servidor, no quisiéramos tener que averiguar lo que ocurre por nuestra cuenta. Contar con soporte técnico para nuestro servidor es algo importante para asegurar el funcionamiento continuo de nuestra página.

Con estas 4 cosas podrás tener un sitio web rápido y seguro. Muchos servicios de alojamiento ofrecen servicios adicionales como correos personalizados, bases de datos, dominios y plugins, entre otros.

Las opciones gratuitas no cuentan con todo esto, pero puedes utilizarlas para probar tu sitio web o para empezar a familiarizarte con todo el proceso de publicar una página. 000webhost.com es una de las opciones de alojamiento gratuito más populares.

Tutorial

Este es un pequeño tutorial para publicar una página web de forma gratuita en 000webhost, haz clic en las flechas para saber más:

El primer paso es registrarnos y confirmar nuestro correo electrónico en la página.

Después de confirmar se nos enviará a una página de bienvenida y al final crearemos un proyecto.

Enseguida veremos un menú con las opciones para nuestro sitio.
Tenemos varias opciones, seleccionamos la última para subir nuestros archivos.

Nos llevará a un administrador de archivos en línea, en la carpeta de public_html deberán ir todos nuestros archivos.
La página de inicio que subas debe llamarse index.html

Ya en la carpeta, seleccionamos el ícono para subir archivos.

Con todos nuestros archivos ya alojados, podemos visualizar nuestra página en el dominio que se nos dió.
