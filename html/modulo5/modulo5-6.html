Responde las preguntas

Haz clic en tu respuesta y presiona Revisar.

  1. Son conceptos y protocolos que permiten el funcionamiento del internet.

    • TCP/IP
    • CSS
    • DNS
    • HTTP

    TCP/IP mueve los datos, DNS traduce nombres a direcciones y HTTP pide y entrega las páginas. CSS solo da estilo.

  2. ¿Qué necesitamos para publicar una página web?

    • Antivirus
    • Servidor de alojamiento
    • Bases de datos
    • Dominio

    El alojamiento guarda los archivos del sitio y el dominio es el nombre con el que se llega a ellos.

  3. Entre más visitantes tengamos en nuestra página, necesitaremos más:

    • Dinero
    • Memoria RAM
    • Espacio de almacenamiento
    • Ancho de banda

    El ancho de banda es la cantidad de datos que el servidor envía; cada visita descarga la página otra vez.

  4. Es el nombre de un sitio web.

    • Alojamiento
    • Dominio
    • DNS
    • Servidor

    El dominio, como tec.mx, es el nombre que escribimos para llegar al sitio.

  5. Son terminaciones de dominios exclusivas para sitios de instituciones gubernamentales y educativas.

    • .com
    • .edu
    • .gob
    • .net

    .edu es para instituciones educativas y .gob para el gobierno; .com y .net los puede registrar cualquiera.

  6. Selecciona 2 ejemplos de frameworks de JavaScript.

    • React
    • Sass
    • Bootstrap
    • jQuery

    React y jQuery son de JavaScript; Bootstrap es un framework de CSS y Sass es un preprocesador de CSS.
