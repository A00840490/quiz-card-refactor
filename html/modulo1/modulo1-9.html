Tema 8 Atajos

Escribir código implica usar el teclado y ratón de manera continua. Para eficientizar esto, existen ciertas combinaciones de teclas que se denominan atajos, que realizan funciones específicas que de otra manera tardarían más tiempo en realizarse.

En Windows, la mayoría de estos se utilizan con la tecla Ctrl junto con una o más teclas, dependiendo de lo que se quiera hacer. En Mac se utiliza la tecla Command en lugar de Ctrl.

Tal vez ya conozcas algunos atajos. Entre los más utilizados están + C y + V para copiar y pegar. A continuación, te mostraremos otros atajos útiles para escribir código; algunos de ellos son exclusivos de VS Code.

Haz clic en los recuadros para conocer más.

Atajos de Archivos

  • + S: Guarda el archivo en el que se está trabajando.

  • + Shift + S: Guardar con nombre y cambiar ubicación (Guardar cómo).

  • + N: Crea un nuevo archivo.

  • + O: Abre un archivo.

Atajos de Edición

  • + Z: Deshacer la última edición.

  • + Y: Rehacer.

  • + F: Buscar texto en el archivo actual.

  • + H: Buscar y reemplazar texto en el archivo.

  • + /: Convertir la selección actual o línea actual en un comentario.

Atajos de Selección

  • + A: Seleccionar todo.

  • + Clic: Crea otro cursor de línea en la posición del mouse, lo cual te permite editar múltiples líneas o secciones del código al mismo tiempo. Haz clic en cualquier parte del archivo para quitar los cursores adicionales.

  • + : Mover la línea actual o líneas seleccionadas hacia arriba.

  • + : Mover la línea actual o líneas seleccionadas hacia arriba.

  • + + Shift: Duplica la línea actual o seleccionadas hacia arriba.

  • + + Shift: Duplica la línea actual o seleccionadas hacia abajo.

Atajos del Editor

  • + W: Cerrar ventana o archivo.

  • + ,: Abrir configuración.

  • + \: Agregar otro editor a la derecha.

  • + K y después + S: Abre todos los atajos de VS Code.
