Frontend y Backend: ¿Qué Significan?

La programación web se divide en dos sectores principales: El Frontend y el Backend que, como sus traducciones al inglés nos indican, son las partes de "enfrente" y "detrás" de un sitio web, respectivamente.

El Frontend es todo lo que podemos visualizar en las páginas del sitio y las interacciones que se realizan desde la computadora del usuario. Incluye todo el código HTML, CSS e incluso JavaScript que puedan tener las páginas. Esto abarca texto, imágenes, animaciones, listas, interfaces, formularios y muchas otras cosas más con las que interactúan los diferentes usuarios.

El Backend es todo lo que está por parte del servidor o servidores en los que se encuentra el sitio web. Entre muchas otras tareas, el back-end se encarga de manejar la información de los usuarios, trabajar con bases de datos y transmitir el contenido.

Con estos dos componentes, podemos crear sitios web funcionales; todo nuestro código y archivos estarán en algún servidor que servirá como Backend y hará llegar estos archivos a nuestros usuarios para así desplegar nuestra página web al mundo. Este curso se enfocará principalmente en el Frontend.

¿Qué es HTML?

HTML es el lenguaje estándar para la creación de páginas web. Sus siglas significan Hyper Text Markup Language o Lenguaje de Marcas de Hipertexto en español. Un lenguaje de marcas incorpora etiquetas o marcas que permiten la estructuración de un documento, donde cada etiqueta describe un elemento de la página web. Este lenguaje técnicamente no es un lenguaje de programación, ya que sólo sirve para dar estructura y no contiene funciones ni variables.

Las etiquetas se acomodan jerárquicamente para describir la manera en que se despliegan los elementos para el usuario. Algunos ejemplos de los tipos de elementos HTML son los títulos (headings), párrafos, divisiones, imágenes y los enlaces. La versión actual de este lenguaje es la 5 (HTML5).

¿Qué es CSS?

CSS quiere decir Cascading Style Sheets, u "Hojas de Estilo en Cascada" en español. CSS es un lenguaje que se usa principalmente para el diseño, ya que permite describir y agregar diferentes características a los elementos HTML. Puede ser utilizado para añadir diferentes estilos de fuentes al texto de una página web, cambiar el color de los elementos, e incluso se puede usar para animar los elementos. También puede modificar otros atributos de los elementos como espaciados, tamaños, márgenes y transparencia, entre muchos otros.

¿Qué hay de JavaScript?

Este sí es un lenguaje de programación. JavaScript se utiliza principalmente para la Web. Cuenta con muchas funcionalidades que nos permiten crear páginas web dinámicas y complejas en su comportamiento. También es el único lenguaje que se puede utilizar nativamente en los navegadores. Sin embargo, no solo nos sirve para agregar funcionalidades a una página web, ya que existen entornos como Node JS que nos permiten utilizar JavaScript fuera del navegador para prácticamente cualquier aplicación.
