Navegador

Un navegador es el software o programa que nos permite acceder a la Web. Este interpreta todo el código de las páginas web a las que accedamos para desplegarlas en nuestra pantalla. Existen muchos navegadores como Chrome, Firefox, Edge o Safari; cada uno cuenta con características diferentes, pero su función es la misma. A diferencia de los navegadores mencionados, algunos otros navegadores pueden interpretar erróneamente código si están desactualizados o no cumplen ciertos requisitos.

Servidor Web

Un servidor, explicado de manera simple, es una computadora ajena que está en funcionamiento 24/7; incluso tu propia computadora puede funcionar como servidor. Los servidores web utilizan el protocolo: HTTP (Hyper-Text Transfer Protocol) para transferir información y manejar todas las conexiones que se establecen entre el servidor y sus clientes (computadoras de los usuarios). Cada vez que alguien quiera ingresar a nuestro sitio web, el servidor le proporciona los archivos necesarios al cliente para que su navegador pueda visualizar las páginas. Por ello, requerimos de algún servicio de hosting (alojamiento) para mantener nuestra página visible para el Internet en todo momento; hay muchas compañías que nos ayudan con esto. El servicio HTTP más popular es Apache, el cual es open-source y gratuito.

Framework

Framework quiere decir entorno de trabajo, el cual consiste en una serie de herramientas y prácticas que nos ayudan a resolver cierto problema. En el contexto del desarrollo web, un framework nos da soporte con módulos y librerías para facilitar nuestro código, o utilizar funciones que serían más complicadas de implementar sin este. Por ejemplo, existen frameworks para incorporar Python en desarrollo web como Django o Flask.

Lenguaje

Un lenguaje en el contexto de programación web es una serie de reglas e instrucciones que permiten realizar cierto tipo de acciones o añadir cierto formato a algún elemento. En este curso aprenderás las nociones de los 3 lenguajes pilares de la programación web y todas sus instrucciones básicas para crear páginas web.
